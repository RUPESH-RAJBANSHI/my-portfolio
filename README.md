# My Portfolio

A personal portfolio website built to showcase my projects and skills as a full-stack developer.

**Live site:** https://your-site.vercel.app *(add this after deploying)*

## Features

- Responsive design that works on mobile, tablet, and desktop
- Sections for About, Projects, and Contact
- Projects loaded from a typed data file, so adding a new one is easy
- Fast loading and SEO-friendly with Next.js

## Tech Stack

- [Next.js](https://nextjs.org/) (App Router)
- [TypeScript](https://www.typescriptlang.org/)
- [Tailwind CSS](https://tailwindcss.com/)
- Deployed on [Vercel](https://vercel.com/)

## Getting Started

1. Clone the repository:
```bash
   git clone https://github.com/RUPESH-RAJBANSHI/my-portfolio.git
   cd my-portfolio
```
2. Install dependencies:
```bash
   npm install
```
3. Start the development server:
```bash
   npm run dev
```
4. Open http://localhost:3000 in your browser.

## Project Structure

```
app/          # pages and layout
components/   # Hero, About, Projects, ProjectCard, Contact
data/         # projects data (projects.ts)
public/       # images and static files
```
